# hamiltonian-monte-carlo-explainer

A visual introduction to Hamiltonian Monte Carlo. Mirrors the structure of
`apps/rectified-flow-explainer/`.

## Developing

```sh
npm install   # from the workspace root
npm run dev --workspace hamiltonian-monte-carlo-explainer
```

## Building

```sh
npm run build --workspace hamiltonian-monte-carlo-explainer
```

## Deploying

```sh
npm run deploy --workspace hamiltonian-monte-carlo-explainer
```

Publishes the static build to `blog/hamiltonian-monte-carlo` on the personal
site repo.
